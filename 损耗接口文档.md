# 损耗计算接口文档

## 请求头

所有接口都需要在请求头携带登录 token，否则返回 401/未登录：

```
token: <登录后获取的token>
```

## 通用返回结构

所有接口返回 `CommonResult` 包装：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {}
}
```

| 字段 | 类型   | 说明                                     |
| ---- | ------ | ---------------------------------------- |
| code | int    | 200 成功；500 业务异常（msg 为具体原因） |
| msg  | string | 提示语                                   |
| data | object | 业务数据，结构见各接口                   |

---

## 1. 条袋损耗数据 GET /biz/loss/stick-data

按**生产订单号**取条袋生产订单的损耗计算数据：主表为订单信息+汇总，分录为用料清单（含理论/实际用量、损耗率），另附带该销售订单下盒装入库折算的条数明细。

### 请求参数（Query）

| 参数    | 类型   | 必填 | 说明                                                                                                        |
| ------- | ------ | ---- | ----------------------------------------------------------------------------------------------------------- |
| fnumber | string | 是   | 注意：参数名叫 fnumber，**实际传生产订单号**（如 MO000123）。订单物料编码必须以 `MP` 开头（条袋），否则报错 |

### 业务异常（code=500）

| msg                            | 触发条件                 |
| ------------------------------ | ------------------------ |
| 未找到生产订单，请检查订单号。 | 金蝶中查不到该生产订单   |
| 该生产订单不是条袋生产订单     | 订单物料编码不是 MP 开头 |

### 返回 data 字段说明（BizLossDO）

| 字段         | 类型   | 说明                                                      |
| ------------ | ------ | --------------------------------------------------------- |
| type         | string | 固定 `条袋`                                               |
| billNo       | string | 生产订单号                                                |
| materialNo   | string | 产品编码（MP 开头）                                       |
| materialName | string | 产品名称                                                  |
| materialSpe  | string | 规格型号                                                  |
| saleOrder    | string | 销售订单号                                                |
| fqty         | number | 订单数量                                                  |
| unit         | string | 单位                                                      |
| seq          | int    | 行号（固定 1）                                            |
| stockQty     | number | 入库数量（生产入库-退库）                                 |
| boxStock     | number | 外包实际入库折算条数（同销售订单下盒装入库数×盒条比汇总） |
| totalTheory  | number | 原材料理论用量合计（不含子项编码 CP/OP 开头的行）         |
| totalReal    | number | 原材料实际用量合计（口径同上）                            |
| lossRate     | string | 总损耗率，如 `2.07%`；实际用量为 0 时为 `-`               |
| entries      | array  | 用料分录（BizLossEntryDO），见下表                        |
| productData  | array  | 盒装产品折算明细（BoxProductDO），见下表                  |
| putData      | null   | 本接口不使用，固定 null                                   |

### entries 元素（BizLossEntryDO）

| 字段                        | 类型    | 说明                                               |
| --------------------------- | ------- | -------------------------------------------------- |
| productNo                   | string  | 子项所属生产订单号（用料单上的）                   |
| fnumber                     | string  | 产品编码（条袋 MP 编码）                           |
| childNo                     | string  | 子项物料编码                                       |
| materialName                | string  | 子项物料名称                                       |
| materialSpe                 | string  | 子项规格型号                                       |
| seq                         | int     | 替代组/行号（同组替代料合并为一行）                |
| unit                        | string  | 单位                                               |
| numerator                   | number  | 分子（用量比例）                                   |
| denominator                 | number  | 分母                                               |
| translateQty                | number  | 调拨量（替代组合计）                               |
| pickedQty                   | number  | 已领数量（替代组合计）                             |
| goodReturn                  | number  | 良品退料数量（替代组合计）                         |
| badReturn                   | number  | 不良品退料数量                                     |
| qty                         | number  | 净用量（已领-良品退-不良退，替代组合计）           |
| theoryQty                   | number  | 理论用量 = 盒装折算条数 × 分子 ÷ 分母              |
| realQty                     | number  | 实际用量（= qty）                                  |
| lossRate                    | string  | 损耗率 = (实际-理论)/实际 ×100%；实际为 0 时为 `-` |
| alternative                 | boolean | 是否替代料合并行（同组多条时为 true）              |
| fstatus                     | string  | 生产订单状态（计划/下达/开工/完工/结案/结算 等）   |
| id / lossId / createTime 等 | -       | 仅保存后才有值，本接口返回 null                    |

### productData 元素（BoxProductDO）

| 字段                              | 类型   | 说明                                             |
| --------------------------------- | ------ | ------------------------------------------------ |
| productNo                         | string | 盒装生产订单号                                   |
| fnumber                           | string | 盒装产品编码（FP 开头）                          |
| fstatus                           | string | 生产订单状态                                     |
| childNo                           | string | 子项物料编码（对应条袋 MP 编码）                 |
| materialName / materialSpe / unit | string | 子项名称/规格/单位                               |
| numerator / denominator           | number | 盒条比分母分子                                   |
| stockNumber                       | number | 盒装入库数量（入库-退库）                        |
| stickNumber                       | number | 折算条数 = stockNumber × numerator ÷ denominator |
| id / lossId                       | -      | 本接口返回 null                                  |

## 2. 盒装损耗数据 GET /biz/loss/box-data

按**销售订单号**取盒装产品的损耗计算数据：取该销售订单下所有 FP 开头（且子项非 MP）的用料分录，按 产品编码+行号 合并替代料后计算理论/实际用量与损耗率。

### 请求参数（Query）

| 参数      | 类型   | 必填 | 说明                      |
| --------- | ------ | ---- | ------------------------- |
| saleOrder | string | 是   | 销售订单号（如 SO000456） |

### 业务异常（code=500）

| msg                            | 触发条件                               |
| ------------------------------ | -------------------------------------- |
| 未能取到数据，请检查销售订单号 | 该销售订单下没有符合条件的盒装用料数据 |

### 返回 data 字段说明（BizLossDO）

| 字段         | 类型   | 说明                                                                  |
| ------------ | ------ | --------------------------------------------------------------------- |
| type         | string | 固定 `盒装`                                                           |
| saleOrder    | string | 销售订单号                                                            |
| entries      | array  | 用料分录（BizLossEntryDO），字段同上接口                              |
| stockQty     | null   | 计算中间值，最终固定返回 null（各行理论用量按各自生产订单入库数计算） |
| 其余主表字段 | null   | billNo/materialNo/fqty/lossRate 等本接口不返回                        |

entries 元素字段与条袋接口相同，差异：

- `theoryQty` = 对应产品生产订单入库数量 × 分子 ÷ 分母
- `realQty` = 净用量 qty
- `lossRate` = (实际-理论)/实际 ×100%；实际为 0 时为 `-`
- 只包含产品编码 FP 开头、子项物料编码非 MP 开头的行
